## 📚 Assignments

### Assignment 1 — NumPy & Pandas

- Create and analyze a NumPy array of student marks
- Calculate mean, median, standard deviation, maximum, and minimum
- Create and filter a Pandas DataFrame
- Calculate student grades dynamically based on marks

### Assignment 2 — Exploratory Data Analysis

- Perform Exploratory Data Analysis (EDA) on the Scikit-learn Wine dataset
- Generate boxplots for numerical features
- Identify potential outliers
- Generate a correlation heatmap
- Identify the strongest positive correlation between features

### Assignment 3 — Regression

- House Price Prediction using Linear Regression
- Multiple Linear Regression using multiple features
- Polynomial Regression
- Compare Linear and Polynomial Regression using the R² score

### Assignment 4 — Data Preprocessing & Feature Scaling

- Create and preprocess a synthetic dataset
- Handle missing values
- Encode categorical data
- Apply StandardScaler
- Apply MinMaxScaler
- Compare StandardScaler and MinMaxScaler

### Assignment 5 — Logistic Regression

- Predict student Pass/Fail using Logistic Regression
- Use Study Hours and Attendance as features
- Experiment with different classification thresholds
- Compare Precision and Recall
- Plot the ROC Curve
- Calculate the AUC score
